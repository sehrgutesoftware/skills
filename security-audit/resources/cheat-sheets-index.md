## Usage

When a finding warrants deeper remediation guidance:

1. Look up the relevant topic in this index.
2. Fetch the sheet URL: `https://cheatsheetseries.owasp.org/cheatsheets/<filename>`
3. Incorporate the specific guidance into the finding's recommendation.

If a topic isn't in this snapshot, check the current full index at https://cheatsheetseries.owasp.org/.
